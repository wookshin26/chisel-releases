# Chisel — Releases

[Chisel](https://chisel-site-mu.vercel.app) is an AI-native, LaTeX-based research tool for macOS and Windows: manuscripts, numerics, figures, literature, and referee review in one project, with an AI that always has your whole project as context.

This repository hosts **downloadable releases** and the **public issue tracker**. The application source lives in a private repository.

## Download

Use the download page — **https://chisel-site-mu.vercel.app** — or the [Releases page](https://github.com/wookshin26/chisel-releases/releases). Each release carries the builds that exist for that version:

| File                                                   | Platform                 |
| ------------------------------------------------------ | ------------------------ |
| `Chisel-<version>-PRIVATE-BETA-UNNOTARIZED-mac-arm64.zip` | macOS 13+, Apple Silicon |
| `Chisel-<version>-PRIVATE-BETA-UNSIGNED-win-x64-setup.exe` | Windows 11, x64          |

The `.sha256` file beside a build is its checksum; the release notes repeat it.

## Private beta status

Every build published so far is a **private beta for invited testers**: the macOS app is not notarized and the Windows installer is not signed.

- **macOS**: on first launch, right-click `Chisel.app` → **Open**. If macOS reports the app as damaged, run `xattr -dr com.apple.quarantine /Applications/Chisel.app`.
- **Windows**: SmartScreen shows "Windows protected your PC". Compare the SHA-256 in the release notes with `certutil -hashfile <installer> SHA256`, then choose **More info → Run anyway** only if it matches. The installer is per user and needs no administrator rights; `%APPDATA%\Chisel` survives upgrades and uninstalls.
- Never disable Defender, SmartScreen, or Gatekeeper for a Chisel build. A build that asks for that did not come from us.

Betas from `v1.3.0-beta.0` on are marked *Pre-release*; the earlier `v1.0.0`–`v1.2.0` alphas are the same kind of build. Signed and notarized production releases will appear as normal releases marked *Latest* when that channel opens.

## Requirements

- macOS 13+ (Apple Silicon) or Windows 11 x64
- [TeX Live](https://www.tug.org/texlive/) with `latexmk` — required for compilation
- Python 3.11+ (or [uv](https://docs.astral.sh/uv/)) — for the Numerics workspace
- Git — for snapshots and review diffs

Chisel does not bundle these tools. The Proof workspace (Lean formal proofs) is a macOS-only experimental beta.

## AI agent connectors (Claude Code · Codex)

This repository also serves as the plugin marketplace for Chisel's approval-gated MCP connectors until they are listed in the official directories. Requirements: Apple Silicon Mac, Node.js 20+, and Chisel running with **Settings → MCP server** enabled.

**Claude Code** (plugin v1.0.6):

```
/plugin marketplace add wookshin26/chisel-releases
/plugin install chisel@chisel
```

Then run `/chisel:chisel-status` in a project-connected session. Update later with `/plugin marketplace update`.

**Codex CLI** (plugin v1.0.6, requires a Codex release with plugin support; commands may vary by version):

```
codex marketplace add github:wookshin26/chisel-releases
codex plugin add chisel
```

Then invoke `$chisel-status`. The connectors never read your API keys; they talk to the local Chisel app only, and every edit or run is approved inside Chisel.
